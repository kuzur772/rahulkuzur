I’m Rahul Kuzur, a software developer passionate about Linux, open-source engineering, and crafting fast, clean applications that work across every platform without unnecessary bloat.

My projects span from low-level experimentation—like designing my own Python-inspired Kuzur Programming Language—to shipping end-user products like KVPlayer, a hardware-accelerated media player distributed across Windows, macOS, Android, FreeBSD, and the Ubuntu Snap Store.

Open-source is my playground. Whether I’m building a zero-dependency HTTP file server, a private file-sharing hub like KShare, or a Flutter chat client like Chatrs, my goal is to craft reliable tools and keep pushing toward scalable, real-time cloud systems.
